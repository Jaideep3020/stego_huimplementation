# Repository visualization and evaluation artifacts

This folder contains 15 demonstrative CHAOS CT cases, alongside evaluation output for all 20 analysed patients and 2,874 slices. The selection only limits the visualization examples; it does not limit the evaluation tables.

Open `../visualization_gallery/README.md` for the inline GitHub gallery. The `cases` folders retain each selected case comparison, metrics, and predicted mask volume. The `evaluation` folder holds the complete per-patient and per-slice matrices, configuration, and summary.
